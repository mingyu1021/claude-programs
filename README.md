# claude-programs

Claude Code를 강화하거나 개발에 쓸 만한 도구(MCP 서버, Skill, 플러그인, CLI)를 **직접 연동·테스트하고 한국어로 정리**한 노트 모음.

- [INDEX.md](INDEX.md) — 도구 목록과 테스트 상태
- [install.md](install.md) — 어디에(전역 / 프론트엔드 / 보안 / 영상 프로젝트) 무엇을 설치할지
- [CLAUDE.md](CLAUDE.md) — 여러 Claude Code 세션이 같은 방식으로 조사·연동·테스트하도록 한 작업 규칙
- [_template/README.md](_template/README.md) — 노트 양식

정리한 도구: Eraser.io · draw.io · ponytail · ECC · impeccable · security-audit-skill (Cloudflare) · HyperFrames

> 각 도구의 원본 저장소 클론(`*/plugin/`, `HyperFrames/src/` 등)은 용량·라이선스 때문에 올리지 않았다. 원본 링크는 각 README에 있다.
> 정보는 정리일(2026-11-08) 기준이며, 요금·기능은 바뀔 수 있다.
